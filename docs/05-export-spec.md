# Export Spec

## Formatos

- Markdown (.md)
- HTML (.html)
- PDF (.pdf)

## Features

- Exportar documento individual
- Exportar carpeta completa
- Incluir assets
- Mantener enlaces internos

## HTML

- Plantilla base
- CSS configurable

## PDF

- Render desde HTML
- Soporte para estilos

## Consideraciones

- Encoding UTF-8
- Manejo de imágenes
- Rutas relativas
