# Product Spec — MarkFlow Studio

## Overview

MarkFlow Studio es una aplicación universal (macOS, iPad, iPhone) para la creación, edición, organización y exportación de documentos Markdown con previsualización en tiempo real.

## Objetivo

Proveer una herramienta moderna, rápida y offline-first para gestionar documentación técnica, notas y conocimiento personal.

## Stack Tecnológico

- SwiftUI
- SwiftData
- Xcode 26.4
- Arquitectura MVVM

## Features Principales

- Editor Markdown avanzado
- Previsualización en tiempo real
- Carpetas virtuales
- Enlaces internos tipo wiki
- Exportación a múltiples formatos
- Base de datos local configurable
- UI moderna basada en Liquid Glass

## Plataformas

- macOS
- iPadOS
- iOS

## MVP

- Crear/editar documentos
- Preview en tiempo real
- Carpetas
- Enlaces internos
- Exportación básica
