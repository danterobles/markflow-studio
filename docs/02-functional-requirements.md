# Functional Requirements

## Documentos

- Crear documento
- Editar documento
- Eliminar documento (soft delete)
- Duplicar documento
- Renombrar documento
- Buscar documentos

## Editor Markdown

- Soporte para:
  - Headers
  - Listas
  - Checklists
  - Tablas
  - Código
  - Links
  - Imágenes

- Helpers:
  - Insertar encabezado
  - Insertar lista
  - Insertar tabla
  - Insertar código
  - Insertar link

## Preview

- Render en tiempo real
- Modo split
- Modo solo editor
- Modo solo preview

## Carpetas

- Crear carpeta
- Carpetas anidadas
- Mover documentos
- Ordenar carpetas

## Enlaces internos

- Sintaxis: [[Documento]]
- Navegación entre documentos
- Detección de enlaces rotos
- Backlinks

## Exportación

- Markdown
- HTML
- PDF

## Workspace

- Selección de carpeta base
- Persistencia local
- Compatible con iCloud/Drive
