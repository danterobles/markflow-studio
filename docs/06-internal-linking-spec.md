# Internal Linking Spec

## Sintaxis

[[Nombre del documento]]

## Comportamiento

- Buscar documento por título
- Si no existe → marcar como enlace roto
- Permitir crear documento desde enlace

## Features

- Navegación entre documentos
- Backlinks
- Vista de relaciones

## Validaciones

- Evitar loops infinitos
- Actualizar enlaces al renombrar documento
