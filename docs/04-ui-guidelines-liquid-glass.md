# UI Guidelines — Liquid Glass

## Principios

- Transparencia (blur + glass effect)
- Minimalismo
- Animaciones suaves
- Jerarquía clara

## Layout

### macOS

Sidebar | Lista | Editor/Preview

### iPad

Sidebar colapsable + Editor

### iPhone

Stack:
Carpetas → Documentos → Editor → Preview

## Componentes

- Sidebar translúcido
- Cards de documentos
- Toolbar flotante
- Inspector lateral

## UX

- Autoguardado invisible
- Transiciones suaves
- Feedback visual inmediato

## Temas

- Light
- Dark
- Adaptativo
